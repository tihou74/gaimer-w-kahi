## كيف ترفع ملفاتك (من المتصفح، بدون أي برامج)

1. افتح المجلد المناسب من القائمة أدناه.
2. اضغط **Add file** ← **Upload files**.
3. اسحب ملفاتك وأفلتها.
4. 🔴 **اضغط زرّ `Commit changes` الأخضر** — الرفع لا يكتمل بدونه.

### ⚠ هذا المستودع عامّ (public)

لازم يكون عامّاً حتى يعمل النشر المجّاني على GitHub Pages. ولذلك:

- **لا ترفع** عقوداً ولا كشوف رواتب ولا أسماء موظفين ولا أرقام إقامات.
  ضعها في مستودعك الخاصّ `alsheikha-hr`.
- ومع ذلك: مجلّد `intake/` و`docs/` **لا يُنشران على الموقع**. النشر يبني

  تسرّب أحدها (`.github/workflows/deploy.yml`).

### قاعدتان أعمل بهما

1. **لا رقم ولا اسم لم تقله.** الهواتف والساعات والجوائز والسعران
   المتعارضان تظهر **فراغاً موسوماً** («في الانتظار») حتى ترسلها. موقع فيه
   هاتف مُخترع أسوأ من موقع بلا هاتف: الزبون يتّصل، لا أحد يجيب، فيظنّ
   أنّكم أقفلتم.
2. **كل صورة تُفحَص قبل النشر** بحثاً عن علامة مائيّة وشعار غريب وصورة شخص
   حقيقي. الأدلّة في `docs/evidence/`.

## الأدوات والحرّاس

كلّها تُشغَّل في CI عند كل دفعة، **ومعها فحصها الذاتي** — وحارس لم يُجرَّب
على عطل معروف لا يُوثق به.

```bash
python3 .kiro/tools/build_menu.py <menu-seed> data/menu.json   # دمج المنيو
python3 .kiro/tools/build_menu_page.py data/menu.json          # توليد الصفحتين
python3 .kiro/tools/check_contrast.py assets/css/tokens.css    # كل نسبة تباين مكتوبة = محسوبة
python3 .kiro/tools/check_assets.py                            # كل أصل موجود + alt + أبعاد
python3 .kiro/tools/check_links.py                             # لا رابط ميّت ولا مرساة غائبة
python3 .kiro/tools/check_ci_wired.py                          # لا فحص غير مربوط بـCI
python3 .kiro/tools/imgguard.py check <ملف>                    # حدّ 2000 بكسل
node    .kiro/tools/imgpipe.js responsive <صورة> <مجلد> <اسم>  # محرّك صور بكروم
node    .kiro/tools/imgpipe.js overflow <صفحة> 390 844         # تجاوز أفقي (فخّ RTL)
```

**مجموع التأكيدات الذاتية: ٥٠** (٧+٧+٦+٨+١٠+٨+٤).

## ترقيم الإصدار والكاش

كاش GitHub Pages يُظهر نسخاً قديمة فيُقرأ «الإصلاح لم يُنفَّذ» وهو منفَّذ.
لذلك: كل أصل محلّي يحمل `?v=N` في HTML، ويُزاد N في كل دفعة. وكل نشر
يكتب بصمته في آخر `index.html` — ابحث بـCtrl+F عن `build:` لتتأكّد أنّ
الذي تراه هو الأحدث.
