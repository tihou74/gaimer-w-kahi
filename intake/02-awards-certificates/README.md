# الشهادات والجوائز

ارفع هنا صور الشهادات والجوائز والتقييمات.

واكتب مع كل واحدة سطراً (أو قُلها في المحادثة):
```
<اسم الملفّ> | الجهة المانحة | السنة | على ماذا
```
مثال: `award1.jpg | بلدية الدوحة | 2024 | أفضل التزام بالسلامة الغذائية`

**لماذا السطر مهمّ:** شهادة بلا جهة ولا سنة لا تُقنع أحداً، وتُقرأ زخرفة.
وشهادة باسم جهتها وسنتها هي الفرق بين «مطعم» و«مطعم بسجلّ خمس سنوات».
